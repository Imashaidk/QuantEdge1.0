# Use of AI tools

AI assistants (including Claude and Antigravity) were used during this project for:

- coding help: drafting and refactoring Python modules and tests
- debugging: tracking down numerical and library-version problems
- drafting: README text, and LaTeX table formatting

The team chose the question, the asset universe, the portfolio weights, the methods and the evaluation design. We ran the code ourselves, checked every result in the report against the output of `run_all.py`, and rewrote or removed claims the results did not support.

We are fully responsible for every methodological choice, line of code, calculation and statement in this submission.
